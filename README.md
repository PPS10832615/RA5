# 🛠️ Laboratorios de DevOps e infraestructura

Bienvenido al repositorio central de prácticas de automatización, integración continua y orquestación. 

Este espacio documenta la evolución arquitectónica de distintos despliegues: desde la creación de Infraestructura como Código (IaC) y la gestión de configuración en máquinas virtuales, hasta la orquestación avanzada de contenedores.
